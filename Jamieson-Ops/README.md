# Jamieson-Ops — Rental-Ready Tech Operations

The working folder for selling and delivering the **Rental-Ready Tech package** to property managers and owners on the Outer Banks. Everything here is a reusable template or tool — adapt per job, nothing is auto-sent.

**Brand:** navy `#002052` / blue `#0099E5`. **Packages:** Essentials $1,300 · Plus $3,534 · Pro $6,202 per door · Managed Plan $49–99/mo. Hardware billed cost + 15–25% markup on a line separate from flat install labor.

---

## The workflow

Run a job left to right. Each step names the document to reach for.

**1 · Inquiry** — someone asks about WiFi / Starlink / rental tech.
→ Reply with template **1 (Initial Inquiry Reply)** in *client files / Client Communication Templates*. Send the **Package One-Pager** if they want to see options.

**2 · Proposal** — you've scoped the property.
→ Build the quote in the **Hardware BOM & Margin Model** (confirm cost + markup, see your margin). Fill the **PM Rental-Ready Proposal** with tier, quantities, and prices. Send it with template **2a (Proposal Send)**; nudge once after 3–5 days with **2b**.

**3 · Close** — they're in.
→ They sign the proposal's Investment Summary (DocuSign-ready). Take the 50% deposit. Confirm the date with template **3a (Scheduling Confirmation)**.

**4 · Install** — day of.
→ Work the **Install & Support Checklist**: pre-install readiness → install + test → log every serial in the **Warranty Tracker** as you go. Text **3b (Day-Before Reminder)** the night before.

**5 · Handoff** — it's working.
→ Finish Section 3 of the checklist (customer walkthrough + sign-off, leave them a copy). Send template **4a (Post-Install Handoff)** with the walkthrough attached, then **4b (Review Request)** 2–4 days later.

**6 · Warranty & recurring** — keep them.
→ Devices live in the **Warranty Tracker**; its Dashboard flags coverage *Expiring <60d*. That's the trigger for template **5b (Warranty-Expiry / Renewal Outreach)** — convert to the Managed Plan. Handle any issue with template **5a (Support Response)** and log it in the tracker's notes.

## Ground rules

- **Draft, don't send.** Every document is a starting point — personalize the `[brackets]`, review, then send/sign yourself.
- **Margin stays visible.** Hardware is always itemized cost + markup, separate from flat labor.
- **The tracker drives recurring revenue.** Its expiry flags tell you exactly when to pitch the Managed Plan.
- **One standard per door.** Same build, same checklist, same warranty — that's the pitch.

*Draft — internal operations index. Pair with the J-Suite app for on-site quoting.*
