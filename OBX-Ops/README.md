# OBX-Ops — field & sales kit

Working drafts for OBX Lot Solutions day-to-day ops: quoting, prospecting, and the house-watch product. Everything here is **draft / internal** until you say otherwise — nothing gets sent, signed, or charged without your go-ahead.

## How the pieces fit (the workflow)

**Win the job → win the account → make it recurring.**

1. **Quote on site** → `Quote Worksheet — House Clear-Out (phone fill-in)`
   Fill it live (or alongside the J-Suite app): rooms → truckloads, dumpster-vs-haul, disposal at $73.16/ton, brother labor, margin, final price. Rehearse first with `monday-quote-rehearsal.html` (in the main project folder).

2. **Find the next customers** → `Top 20 PM Targets — House-Watch & Washing`
   Ranked property/rental managers, tagged washing-first vs house-watch-first, with phones. Start with the ★ verified numbers.

3. **Make the calls** → `Cold-Call Script — House-Watch & Washing`
   Opener, pitch (washing for big VRMs, house-watch for HOA/residential PMs), objection handling, log codes. Goal of each call: book a 5-minute walkthrough.

4. **Land the house-watch client → deliver a pro product** → the house-watch kit:
   - `OBX Lot Solutions — Home-Watch Service Agreement [INTERNAL DRAFT]` — tiered plans, terms, signature blocks. ⚠️ Carries a **"DRAFT — attorney review required"** banner; have a NC attorney review and confirm insurance/vacancy language before any client sees it.
   - `OBX Lot Solutions — Property Watch Report (template)` — the branded photo report you send after every visit. This is what makes the account *sticky*.

5. **Run your week** → `Monday Action Brief`
   Today's quote visit, this week's top 3, and the prioritized call list to start from. Regenerated each week.
