# DevOps Handoff — Crew Job Checklists (app-ready)

The 8 crew SOPs are packaged here as structured JSON for DevOps to surface as **in-app, crew-facing job checklists** (the "crew runs off their phone" need). No print cards — this is the app feed.

## Files
- **`crew-checklists.json`** — the data. One object per service line (8 total).
- Generated by **`../build-app-checklists.py`** from **`../SOPs/*.md`**.

## Source of truth & drift
The **SOP markdown is the source of truth.** This JSON is a generated view — don't hand-edit it. When an SOP changes, re-run:

```
python3 OBX-Ops/Crew-Playbook/build-app-checklists.py
```

Same drift-proof pattern as the inventory lenses: edit source → regenerate.

## Schema (`obxls.crew-checklist.v1`)
```jsonc
{
  "schema": "obxls.crew-checklist.v1",
  "source_of_truth": "OBX-Ops/Crew-Playbook/SOPs/*.md",
  "count": 8,
  "checklists": [
    {
      "id": "04",
      "line": "junk",                 // stable key to tie a job to its checklist
      "title": "Junk Removal / Clear-Outs",
      "tier": "SPINE",                 // SPINE | SECONDARY
      "pricing_guardrail": "...",      // show as read-only reference to the crew
      "source": "OBX-Ops/Crew-Playbook/SOPs/04 Junk.md",
      "sections": [
        { "name": "Intake / before you roll",
          "items": [
            { "text": "Bed-bug question (scripted)...", "check": true },
            { "text": "Price the dump fee into the job...", "check": false }
          ] }
      ],
      "guards": [ "Hazardous (paint, chemicals...) -> don't haul; flag", "..." ]
    }
  ]
}
```

## Rendering guidance for the app
- **`check: true`** items → tickable checkboxes the crew completes on site (gate job close-out on the required ones if you want).
- **`check: false`** items → informational lines (scope caps like "IN/OUT", disposal pricing rules) — show, don't tick.
- **`guards`** → render as a distinct **"Stop / escalate / refer"** callout (the don't-cross lines).
- **`pricing_guardrail`** → read-only reference; the crew quotes within it, never re-prices (owner sets price).
- Tie a job's service line to its checklist via **`line`** (matches the quote-tool service categories).

## Coverage (this build)
SPINE: home-watch (3 sec / 17 steps), washing (4 / 10), yard-mowing (4 / 9), junk (5 / 16).
SECONDARY: cleanup (3 / 10), brush (4 / 13), shed-demo (3 / 10), gutters (4 / 15).
All carry their guards + pricing guardrail. The debrief lessons (bed-bug, move-out sequencing + disposal sign-off, ladder safety, scope caps) ride along inside the relevant SOP items.
